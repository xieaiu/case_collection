# 京东搜索 h5st / x-api-eid-token 入口记录

## 目标请求

- 页面：`https://search.jd.com/Search?keyword=衣服&enc=utf-8`
- 方法：`GET`
- 接口：`https://api.m.jd.com/api`
- 业务标识：`appid=search-pc-java`、`functionId=pc_search_searchWare`
- 结果：浏览器登录态下 HTTP 200，搜索数据正常返回

## 已闭环的调用链

```text
搜索页面动作
  -> search bundle Bm
  -> xhr
  -> Axios XHR adapter
  -> 最终 URL
  -> x-api-eid-token = window.getJsToken(callback)
  -> h5st = window.PSign.sign(d).h5st
```

## 入口位置

### 业务请求构造

- 脚本：`https://storage.360buyimg.com/retail-mall/main_search/pro/0.0.11/js/index.9f0c5ba0.js`
- 代码位置：原始压缩脚本第 10 行；运行时断点调用栈约第 10 行、第 69652 列
- 请求函数：`Bm`（第 74601 列附近），内部调用 `xhr`（第 67693 列附近）
- 证据：断点现场的 Axios config 已包含完整业务 URL；`url` 中已有 `x-api-eid-token` 与 `h5st`

### h5st

- 入口：`window.PSign.sign(d)`
- `d` 形态：
  - `appid: "search-pc-java"`
  - `functionId: "pc_search_searchWare"`
  - `client: "pc"`
  - `clientVersion: "1.0.0"`
  - `t: Date.now()`
  - `body: SHA256(JSON.stringify(signBody))`
- 页面初始化：当前页面内联脚本第 6–19 行创建 `window.PSign`
- 配置：`appId: "f06cc"`、`preRequest: false`
- `h5st` 结构：分号分隔多段；当前样本为 8 段，首段为时间串，整体为混合字母数字/`_`/`-` 字符

### x-api-eid-token

- 入口：`window.getJsToken(callback, 200)`
- 脚本来源：`https://gias.jd.com/js/pc-tk.js?v=2024-06-20-17`
- 特征：设备/环境指纹链路，状态中包含 `jsToken`、`eid`、`fp`；读取 userAgent、screen、timezone、storage、canvas、WebGL 等环境信息

## 安全 SDK 落点

- `ParamsSign` 定义：`https://storage.360buyimg.com/webcontainer/js_security_v3_0.1.6.js?v=2024-06-20-17`
- 导出：`window.ParamsSign`
- 实例方法：`sign`、`signSync`
- 文件特征：字符串数组 + 控制流/变量混淆；不适合继续按业务明文搜索
- `getJsToken` 实现：`https://gias.jd.com/js/pc-tk.js?v=2024-06-20-17`，同样为混淆风控脚本
- 页面辅助脚本：`https://storage.360buyimg.com/webcontainer/main/js-security-v3-rac.js?v=20260905`

- `x-api-eid-token` 类型：环境读取型设备指纹 token
- 下一步：若要还原源码结构，转 `ast-deobfuscate`；若要脱离浏览器运行，先以 `ParamsSign.sign` 和 `getJsToken` 为入口转 `env-patch`
